# Life OS Static Starter Site

This folder contains a static page (`index.html`) compatible with GitHub Pages.

## Use
1. Enable GitHub Pages from `docs/site` (or publish this folder via your preferred static host).
2. Open the page and enter your API base URL (e.g. `http://localhost:3000` for local dev).
3. Click **Load Overview** to fetch dashboard data from `/api/overview`.

## Note
If hosted on GitHub Pages, your backend API must be publicly accessible and configured for CORS.


## Demo fallback
If API is unreachable/CORS-blocked, the page automatically shows demo data so you can verify the static site works.
You can also click **Use Demo Data** manually.
